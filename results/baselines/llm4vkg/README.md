# LLM4VKG baseline

`table2.csv` contains the LLM4VKG comparison values reported in Table 2 of
the MA4ROM paper. They are supplied for comparison only.

The audited local LLM4VKG checkout did not contain its original baseline
mapping, ontology, query metrics, manifest, or run-level provenance. Its
`outputs/default` directories were MA4ROM artefacts and therefore were not
copied or relabelled as LLM4VKG results.

Consequently these values are explicitly marked `reported_only`. They must not
be described as a local rerun or as independently reproduced by this release.
